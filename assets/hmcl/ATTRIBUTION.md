# HMCL UI assets

The PNG images, wallpaper and SVG path data in this directory are copied from
`HMCL-main/HMCL/src/main/resources/assets/img` and
`HMCL-main/HMCL/src/main/java/org/jackhuang/hmcl/ui/SVG.java`.

Source: https://github.com/HMCL-dev/HMCL

SVG.java identifies most icons as Google Material Symbols, normalized to a
24 × 24 view box; its source includes annotations for exceptions. The Rust
implementation retains the original path data rather than substituting emoji.

reference-blue.css is an unmodified reference copy of the original theme palette.
