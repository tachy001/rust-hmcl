These desktop icons are generated from this project's original Aster mark,
`assets/aster/mark.svg`, using Tauri CLI 2.12.3:

`npm run tauri -- icon assets/aster/mark.svg --output <temporary directory>`

Only the Windows ICO, macOS ICNS and desktop PNG files are retained here.
The mark is original vector artwork created for Aster Launcher and follows the
project's GPL-3.0-or-later license. Third-party game and UI assets are credited
separately in `../../assets/hmcl/ATTRIBUTION.md`.
