These desktop icons are derived from `assets/hmcl/logo.png` using Tauri CLI 2.12.3:

`npm run tauri -- icon assets/hmcl/logo.png --output <temporary directory>`

Only the Windows ICO, macOS ICNS and desktop PNG files are retained here.
