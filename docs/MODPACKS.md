# 整合包导入

在侧栏“整合包”选择或拖入本机 `.mrpack`，读取包信息后填写新实例名称并安装。预览显示包名、版本、描述、Minecraft／加载器和客户端文件数量。默认不安装可选客户端文件；服务端专用文件始终跳过。

当前支持原版、Fabric、Quilt。Forge／NeoForge 与未知依赖在读取阶段拒绝，不会开始下载。实例名称不能与基础 Minecraft 版本相同，也不能覆盖已有完整实例。

安装复用已有游戏下载、哈希校验、加载器和任务取消流程。新实例使用独立目录存放整合包文件，并单独设置 `isolated=true`，不改全局隔离偏好。客户端覆盖文件在公共覆盖之后应用。最终实例配置以不替换现有目标的方式提交；成功后核对路径并清理本实例的暂存副本，清理失败仅记入日志。

预览记录源文件 SHA-1；安装前再次检查来源。中断导入可使用同一个文件、同一个名称继续，前提是未完成目录中的来源标记匹配且没有完整实例配置。已下载的基础文件与包文件按现有校验规则复用。安装过程中源包改变会报错；不会执行包内程序。

## 实现和验证

`src/modpack.rs` 负责索引／覆盖路径预检、预览、目标检查与安装；`src/service.rs` 暴露只读预览和后台任务。Tauri 的任务开始及状态读取在工作线程执行，避免大文件预检阻塞原生界面。

`PackInstaller.vue` 提供选择／拖入、预览、命名、可选项和完成入口。系统文件选择器在隐藏验证模式下拒绝弹出，合成拖入事件只用于验证，正常运行使用系统事件。

核心测试覆盖不创建目录的预览、保留名称建议、源文件绑定、同来源继续导入、已有实例拒绝和危险覆盖路径在任何安装目录创建前失败。

Web 与 Windows 原生检查均用独立的手工 ZIP 索引和缓存样本，验证完整预览与安装、命名冲突、独立目录、客户端覆盖优先级、可选／服务端文件跳过、源文件及缓存不变、暂存清理和完成刷新。样本客户端是从不执行的普通字节，不代表实际 Minecraft 或远程加载器安装已经验收；没有启动 Java 或游戏。
