# 本地模组与资源包导入

在游戏库管理一个实例，进入模组管理或资源包管理。选择文件，或将本机文件拖入页面；待导入列表支持移除单项与清空，再点击“导入”开始后台任务。

- 模组接受 `.jar` 文件；资源包接受 ZIP 与文件夹，文件夹需符合资源包结构。
- 每批最多 256 项；取消文件选择保留已有的待导入列表。
- 导入按明确的实例 ID 读取其有效隔离／共享目录，不依赖后台过程中可变的页面选择。
- 导入复制内容，保留源文件。同名目标与重复的目标名称拒绝覆盖；模组先复制到临时文件，再以不替换目标的方式提交。
- ZIP 保留原始字节，不解压到游戏目录；文件夹导入保留内容与空目录。导入不修改资源包启用列表，需在资源包列表另行启用。
- 任务可停止；模组复制按块检查取消，资源包在当前项目完成后处理取消。批次中已完成的项目会保留，日志记录完成数量；失败不会移动源文件。

实现入口：`src/imports.rs`、`src/mods.rs`、`src/resourcepacks.rs`、`src/file_ops.rs`、`frontend/src/LocalImport.vue`。系统选择器由 Tauri 内部的 `pick_import` 调用 rfd，不向网页暴露通用文件系统接口。

## 验证范围

核心测试覆盖只读预检、实例绑定、非法路径／类型／重复名称拒绝、取消前不创建游戏目录、源文件保留，以及并发导入只允许一个完整文件成功提交。

Web 集成验证以独立的手工 JAR 字节与标准 ZIP 作为样本。文件选择结果由无窗口验证桥提供，实际任务与复制由共用 Rust Service 执行，检查选择取消、移除、清空、冲突、字节一致性及资源包选项不变。

Windows 原生验证使用真实发布程序、WebView2 和 IPC，以合成的 Tauri 拖入事件走完整预览与提交流程。隐藏验证模式明确拒绝弹出系统选择器，没有发送桌面鼠标键盘输入，没有执行 JAR、Java 或游戏。系统选择窗口、物理拖动手势及 Linux/macOS 的交互仍待实际桌面验证。
