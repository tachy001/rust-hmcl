# 星屿 Aster 设计方向

用户将目标调整为“发挥自己的创意，做一个全新的启动器”。当前产品采用原创品牌和界面，不再以逐像素还原 HMCL 为验收标准；Windows、Linux、macOS 和 Rust 核心的方向保持不变。

## 当前设计

- 原创星形标记与代码绘制的浮岛、传送门、月亮和轨道。
- 深林色／薄荷绿默认主题与浅色主题，尊重已有配置中的主题选择。
- 首页整合实际账户、当前实例、有效内存、收藏、快捷启动和 Java 设置入口。
- 游戏库支持收藏筛选与搜索；收藏写入 Rust 配置。
- 场景漂浮、页面切换、按压、焦点、开关与弹窗动效；减少动画设置及系统偏好优先。
- 版本选择支持方向键、Home／End、Esc 及关闭后焦点恢复。
- 下载、账户、Java、设置、模组、资源包、实例管理和日志页沿用统一视觉体系。
- 模组页分为本地管理和在线发现：本地名称筛选、启用统计；在线按 Minecraft 与 Fabric／Quilt 环境匹配 Modrinth 项目，后台安装并保留取消和错误反馈。
- 本地导入提供文件选择与拖入、待导入列表、移除和清空；后台复制保留源文件并拒绝同名覆盖，资源包导入与启用分开操作。
- 整合包提供来源选择、只读预览、命名与可选文件设置，安装为独立实例；保持原有任务进度、取消、来源绑定和继续导入能力。

首页不编造游玩时间或安装数量。实例来自真实目录扫描，账户与设置来自共用 Rust Service。没有游戏时提供安装入口。

## 保留与边界

保留现有配置路径、内部 crate 名和启动参数。原生圆角继续使用透明背景和统一裁切，最大化与全屏恢复直角。

HMCL 的功能与过去还原记录作为研究资料；PCL 的控件状态和动画组织作为补充阅读。没有复制 PCL 的代码、图标或界面素材。保留使用的 HMCL 素材继续署名。

当前为预览版。后续重点包括认证、加载器覆盖、模组与整合包流程、资源导入、安装错误恢复和三端实际游戏运行验证，不能用界面截图代替这些验收。
