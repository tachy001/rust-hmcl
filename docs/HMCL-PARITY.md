# HMCL 还原进度与验收

目标保持为完整还原参考 HMCL 的界面、交互、动画和启动器功能。Rust 启动器本身无需 Java，游戏仍由 Java 运行，支持 Windows、Linux 和 macOS。不能把局部界面更新或编译通过视为完整还原。

参照为本机相邻目录 `../HMCL-main/`，重点源文件如下：

- 首页：`HMCL/src/main/java/org/jackhuang/hmcl/ui/main/MainPage.java`。
- 侧栏：同目录 `RootPage.java`。
- 游戏列表：`ui/instances/GameListPage.java`、`GameListCell.java`。
- 控件尺寸与颜色角色：`HMCL/src/main/resources/assets/css/root.css`。
- 动效：`ui/animation/ContainerAnimations.java`、`ui/decorator/Decorator.java`。
- 设置与主题：`ui/main/LauncherSettingsPage.java`、`theme/`。

## 当前证据

- 原 HMCL 图标和默认壁纸已内嵌，来源与许可保存在 `assets/hmcl/ATTRIBUTION.md`。
- 首页已从自定义欢迎卡片和底部大面板改回简洁壁纸与右下角分体启动按钮。原版启动区宽 230、高 57；当前实现采用相同尺寸，菜单箭头展开/收起 200 ms。
- 标题栏改为 40，侧栏改为 200；全窗口壁纸与半透明侧栏恢复。
- 游戏列表改为单选按钮、32 像素游戏图标、两行版本信息、右侧启动与更多操作。保留设置、收藏、目录、模组、加载器安装及修复入口；右键版本正文可打开同一操作菜单。
- 版本信息从继承配置与加载器依赖读取，在刷新列表时缓存，不逐帧读磁盘。
- 按钮悬停、按压、水波纹、开关滑动与页面淡入仍保留；默认开启动画。
- 之前完成 Windows 游戏安装与启动测试。本轮未操作桌面，不能宣称新界面已通过截图或实际窗口验证。
- 已加入 --render-ui 软件预览，直接渲染实际布局、字形和图标网格，不创建窗口、不读桌面、不保存配置；已查看浅色首页、深色实例列表及 860×560 外观页预览。它发现并帮助修复了背景图层遮盖控件的问题，相关回归测试已通过。
- 侧栏当前实例入口与实例列表、下载名称已按原版恢复；默认皮肤使用 TexturesLoader 的 UUID.hashCode / floorMod 规则及原始 18 款资源，头像脸部与帽子分别绘制。
- 实例管理已由弹窗转为页面，按 GameInstancePage 的实际 Skin 使用左侧分页与下方工具入口（截图位于管理菜单）。标题显示实例名，返回原入口，内容切换采用 400 ms 淡入与滑动；曲线与全部细节仍需逐项比对。
- 实例独立窗口尺寸、隔离与自动下载设置已完成序列化、继承、范围验证及启动参数/目录传递测试；实例模组支持导入、切换启用状态。资源包、世界、原理图、截图目前仅列出与打开本地内容，不能视为这些管理功能完整实现。
- Java 管理已使用原版式主版本块与两行紧凑列表，提供本机发现、登记、选择、目录、隐藏/恢复。后台探测去重 Java_HOME 别名，Windows 进程保持隐藏，版本探测有超时。实际识别本机 Oracle Java 8/26、Microsoft Java 17/21、Eclipse Temurin Java 17 共 5 个环境；Linux/macOS 探测目录尚需真机验证。
- 实例复制和重命名已接入菜单、模态对话框与后台任务。测试覆盖数据保留、同名拒绝、取消、继承更新、写入失败回滚和配置迁移。在 `../.tools/instance-operation-proof/` 使用真实 Minecraft 1.20.1 和 Fabric 文件单独核验：副本与重命名实例的 JAR SHA-256 和原文件相同，Fabric 继承指向新名称，原测试实例未变。本轮未启动游戏。

接续未提交改动，先检查状态，不重置、不删除用户数据、不强制推送。每轮写清实际完成项、检查结果和下一项；未验证的内容保持待验，不声称“完美还原”。
