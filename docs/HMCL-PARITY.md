# HMCL 还原进度与验收

目标保持为完整还原参考 HMCL 的界面、交互、动画和启动器功能。Rust 启动器本身无需 Java，游戏仍由 Java 运行，支持 Windows、Linux 和 macOS。不能把局部界面更新或编译通过视为完整还原。

参照为本机相邻目录 `../HMCL-main/`，重点源文件如下：

- 首页：`HMCL/src/main/java/org/jackhuang/hmcl/ui/main/MainPage.java`。
- 侧栏：同目录 `RootPage.java`。
- 游戏列表：`ui/instances/GameListPage.java`、`GameListCell.java`。
- 控件尺寸与颜色角色：`HMCL/src/main/resources/assets/css/root.css`。
- 动效：`ui/animation/ContainerAnimations.java`、`ui/decorator/Decorator.java`。
- 设置与主题：`ui/main/LauncherSettingsPage.java`、`theme/`。

## 当前证据

- 原 HMCL 图标和默认壁纸已内嵌，来源与许可保存在 `assets/hmcl/ATTRIBUTION.md`。
- 首页已从自定义欢迎卡片和底部大面板改回简洁壁纸与右下角分体启动按钮。原版启动区宽 230、高 57；当前实现采用相同尺寸，菜单箭头展开/收起 200 ms。
- 标题栏改为 40，侧栏改为 200；全窗口壁纸与半透明侧栏恢复。
- 游戏列表改为单选按钮、32 像素游戏图标、两行版本信息、右侧启动与更多操作。保留设置、收藏、目录、模组、加载器安装及修复入口；右键版本正文可打开同一操作菜单。
- 版本信息从继承配置与加载器依赖读取，在刷新列表时缓存，不逐帧读磁盘。
- 按钮悬停、按压、水波纹、开关滑动与页面淡入仍保留；默认开启动画。
- 之前完成 Windows 游戏安装与启动测试。本轮未操作桌面，不能宣称新界面已通过截图或实际窗口验证。
- 已加入 --render-ui 软件预览，直接渲染实际布局、字形和图标网格，不创建窗口、不读桌面、不保存配置；已查看浅色首页、深色实例列表及 860×560 外观页预览。它发现并帮助修复了背景图层遮盖控件的问题，相关回归测试已通过。
- 侧栏当前实例入口与实例列表、下载名称已按原版恢复；默认皮肤使用 TexturesLoader 的 UUID.hashCode / floorMod 规则及原始 18 款资源，头像脸部与帽子分别绘制。
- 实例管理已由弹窗转为页面，按 GameInstancePage 的实际 Skin 使用左侧分页与下方工具入口（截图位于管理菜单）。标题显示实例名，返回原入口，内容切换采用 400 ms 淡入与滑动；曲线与全部细节仍需逐项比对。
- 实例独立窗口尺寸、隔离与自动下载设置已完成序列化、继承、范围验证及启动参数/目录传递测试；实例模组支持导入、切换启用状态。世界、原理图目前仅列出与打开本地内容，不能视为这些管理功能完整实现。
- 资源包页已对照 ResourcePackListPage / ResourcePackManager 接入后台 ZIP / 目录包图标和描述、详情、本地搜索、多选、ZIP 批量导入以及单个／批量启用禁用。启用状态写入有效游戏目录 options.txt；不兼容包先确认。兼容性从真实客户端 JAR version.json 读取，覆盖原版旧 pack_format、supported_formats 及新主／次版本范围。44 项本地测试通过，覆盖文件字节保留、同名拒绝、设置内容与顺序保留、改变／损坏设置拒绝、部分导入失败和窄窗口布局。
- 使用 `../.tools/resourcepack-proof/` 复制真实 1.20.1 配置和客户端 JAR，在独立目录核验兼容包、旧格式包和目录包；原参考游戏未运行或修改。ZIP SHA-256 不变，启用／禁用后 fov、语言及自定义字段保留。浅色列表、800×560 深色列表、详情和兼容性确认离屏预览完成，preview-proof.json 记录 options.txt 未变。资源包删除、在线下载／更新、目录包导入、拖放、格式化描述、完整键盘操作和原版工具栏动画仍待还原；尚未证明游戏实际加载及 Linux/macOS 原生运行。导入及创建新 options.txt 的提交当前使用同目录硬链接，非支持文件系统仍需补齐。

## 待还原和待验证

0.3.11 加入全局与实例的窗口／全屏设置，默认旧配置保持窗口模式，实例可显式覆盖全局或恢复继承。按原 DefaultLauncher 末尾追加 --fullscreen，仍保留窗口尺寸；现代、旧版参数与去重测试通过。只读 --launch-plan 使用实际元数据与有效实例配置，无需 Java、安装或创建游戏目录。`../.tools/window-mode-proof/launch-proof.json` 记录真实 1.20.1 元数据的窗口覆盖（0 个标记）、全屏覆盖与全局继承（各 1 个标记）；配置与原游戏 JAR 未被预览改动。查看浅色实例页、深色窄窗口及完整设置页验证控件布局。50 项本地测试通过，4 项联网测试跳过；游戏窗口最大化模式、完整原版窗口设置布局和三端实际全屏画面仍待验证，不用参数检查代替实际运行。

0.3.9 已接入实例分页的旧内容快照退出、400 ms 原版强调曲线和视口高度 20% 上滑；内存绘制快照不会重跑旧页操作，纹理保留与释放已通过测试。连续帧、过渡控件颜色与实际窗口仍待核验。

0.3.10 加入 --render-motion，通过实际 Launcher.draw 输出设置→组件分页的连续帧，并修正 400 ms 浮点边界。内存 UI 输入测试核验过渡期间的鼠标／键盘拦截、期限结束恢复点击与减少动画立即交互。连续离屏帧已经暴露控件额外灰化，仍需修正并与原版逐帧比对；不能因曲线测试通过就宣称完整动效还原。

最终 0.3.10 的 48 项本地测试通过，4 项联网测试跳过；`dist/previews/tab-motion-fixed-light/`、`tab-motion-fixed-dark/`、`tab-motion-fixed-reduced/` 保存实际 0～500 ms 连续帧。查看浅色 400 ms 帧确认恢复正常交互样式；减少动画 0 ms 帧直接显示新内容。`../.tools/resourcepack-proof/motion-proof-0.3.10.json` 记录配置与 options.txt 的 SHA-256 未变。整个核验不调用 App.update 的原生窗口路径，也不触及用户桌面。

Windows 主窗口新增原生圆角区域，12 个逻辑像素半径，按原生 DPI 与窗口尺寸更新，最大化取消区域。隐藏窗口实际 API 测试已核验角点排除、中心与边缘保留、不同尺寸／DPI 和区域清除。参考：[SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn)、[CreateRoundRectRgn](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createroundrectrgn)。离屏软件预览不经过原生窗口裁剪，因此不能用矩形 PNG 判断这项效果；Linux/macOS 外沿圆角仍待实现及真机验证。
